# 猫咪 APNG 帧动画

20 种姿态，每种对应一个 `cat-01.png` 至 `cat-20.png` 的透明 APNG 和一个 `-still.png` 静态首帧。

由 `scripts/generate-cat-apng.py` 使用 Pillow，从已抠图的 `pixel-cat-poses-transparent.png` 生成，原素材保留。每个动画画布 192 × 192，24 个时间采样、每个 120ms，完整循环 2.88 秒；编码时相同帧合并，因此文件中实际为 11–24 帧。

摇摆、跳跃、呼吸和漂浮都已编码进 PNG 帧。动作来自整张姿态的位移、旋转和缩放，未重新绘制肢体。所有帧保留透明 Alpha，采用整帧替换避免拖影。

CatPose.vue 使用 img 显示 APNG；关闭页面动效或启用系统减少动态效果时切换到对应静态 PNG。刷新随机姿态的逻辑保持不变。

生成脚本检查了每个文件的帧数、循环时间、透明像素和前景边界。
